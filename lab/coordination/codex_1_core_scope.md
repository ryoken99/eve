# Codex 1 Core Scope

Codex 1 works on the Eve core.

## Owned Areas

- admin capability model;
- transcript schemas and indexes;
- consolidation signals and memory decisions;
- layered memory contracts;
- semantic/vector memory provider contracts;
- dream schemas and dream-to-lab decisions;
- awareness/world state contracts;
- personality and preference maturation;
- lab candidate lifecycle;
- error memory contracts;
- research classification;
- learning routing;
- autonomous improvement planning;
- ARSI core loop;
- autonomous intent model;
- point reports and coordination docs.

## Not First Priority

Codex 1 should not spend primary effort on physical browser/UIA/Windows runtime. It may define contracts, fallback order and integration points, but Codex 2 validates real execution.

## Delivery Rule

Every point must have a report under `lab/reports/` and at least one file/function that makes the point concrete.
