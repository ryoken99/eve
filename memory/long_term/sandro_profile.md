# Sandro Profile

Sandro quer uma Eve local que nao seja apenas chatbot. A Eve deve falar no terminal, usar Codex/OpenAI auth, lembrar-se, criar skills, programar, usar o PC como humano e evoluir com seguranca.

Preferencias estaveis conhecidas:
- Respostas praticas e diretas.
- A Eve deve estar em `D:\Eve`.
- O login deve ser proprio da Eve, sem depender de Hermes ou OpenClaw.
- A Eve deve entrar direto no chat se ja houver login.
- Deve ser possivel escolher o modelo Codex.
