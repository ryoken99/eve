# Eve Memory System Policies

This folder may contain generic memory policies, schemas, and examples.

Safe to version:

- generic `.yaml` policies;
- `.example.json` files with fictitious data;
- `.example.yaml` files with fictitious data;
- this README.

Not safe to version:

- real imported memory manifests;
- real identity card manifests;
- real current session files;
- real self-state snapshots;
- files containing tokens, private conversations, health information, or personal details.
